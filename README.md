# ASC Registry

AI Security Controls (ASC) Registry is an open standard for describing AI security controls as machine-readable, testable, and versioned artifacts.

## Why?

Most AI security guidance exists as static documents.

Static documents cannot be validated, monitored, or integrated into engineering pipelines.

ASC defines AI security controls as structured artifacts that can be:

- Implemented
- Tested
- Monitored
- Versioned

## Example

ASC-001: Prompt Injection Protection

## Repository Structure

/schema

Defines the ASC control schema.

#/controls

Contains official ASC controls.

#/validation

Contains validation tooling.

#/docs

Contains governance and namespace documentation.
