# Contributing to ASC Registry

Thank you for your interest in contributing to ASC Registry.

## Ways to Contribute

- Propose new AI security controls
- Improve existing controls
- Submit framework mappings
- Add validation tests
- Enhance documentation
- Report bugs

## Before Contributing

Please review:

- README.md
- GOVERNANCE.md
- RFC_PROCESS.md

## Control Submission Requirements

All controls must include:

- Unique ASC identifier
- Purpose
- Risks addressed
- Implementation guidance
- Validation requirements
- Monitoring requirements
- References

## Pull Requests

Pull requests should:

- Follow repository structure
- Pass validation checks
- Include supporting references
- Avoid duplicate controls

## Questions

Open a GitHub Issue for discussion before proposing large changes.
