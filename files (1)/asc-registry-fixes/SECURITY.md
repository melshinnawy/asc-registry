# Security Policy

## Supported versions

ASC Registry is maintained on the latest `main` branch.

## Reporting a vulnerability

Please report privately. Do **not** open a public issue for security problems.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

This covers the validation tooling, CI workflows, published controls, and documentation integrity. Please include the issue, its impact, reproduction steps, and a suggested fix if you have one.

## Responsible disclosure

Please allow maintainers a reasonable opportunity to review and fix an issue before any public disclosure. We aim to acknowledge reports within 7 days.
