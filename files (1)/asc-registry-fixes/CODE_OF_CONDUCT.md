# Code of Conduct

## Our Standards

Participants are expected to:

- Be respectful
- Be constructive
- Focus on evidence-based discussion
- Encourage collaboration
- Welcome new contributors

## Unacceptable Behavior

Examples include:

- Harassment
- Personal attacks
- Discrimination
- Spam
- Bad-faith contributions

## Enforcement

Project maintainers may remove content or restrict participation when behavior violates this Code of Conduct.

## Reporting

To report a violation, use the repository's **Security** tab (private report) or contact the maintainer through their GitHub profile. Reports are handled confidentially.
