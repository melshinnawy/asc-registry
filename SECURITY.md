# Security Policy

## Supported Versions

ASC Registry is currently maintained on the latest main branch.

## Reporting Vulnerabilities

If you discover a security issue affecting:

- Validation tooling
- Automation workflows
- Published controls
- Documentation integrity

Please open a private security report or create an issue describing:

- The issue
- Impact
- Reproduction steps
- Suggested remediation

## Responsible Disclosure

Please avoid publishing security issues publicly before maintainers have an opportunity to review and address them.
