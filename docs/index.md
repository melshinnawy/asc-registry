# ASC Registry

## The Open AI Security Controls Standard

ASC (AI Security Controls) Registry is an open standard for defining AI security controls as machine-readable, testable, and monitorable artifacts.

ASC enables organizations to operationalize AI security through structured controls, validation mechanisms, framework mappings, security tests, and deployment use cases.

---

## Why ASC?

Traditional AI security guidance is often:

- Fragmented across multiple frameworks
- Difficult to automate
- Hard to validate consistently
- Challenging to integrate into engineering workflows

ASC addresses these challenges with an operational security control model.
